RFID Based Attendance System

Project Overview

The RFID Based Attendance System is an embedded systems and IoT-based project designed to automatically record attendance using RFID technology. The system uses an RFID reader and RFID cards to identify individuals. When a registered RFID card is scanned, the system detects the card ID and records the attendance automatically.

This project reduces manual attendance work, saves time, and improves attendance management.

Technologies Used

- Arduino UNO / ESP32
- RFID Reader (RC522)
- RFID Cards / Tags
- LCD Display
- Arduino C++
- Wokwi Simulator

Features

- Automatically records attendance using RFID cards.
- Identifies registered users through unique card IDs.
- Displays attendance status on an LCD.
- Reduces manual attendance recording.
- Provides a simple and efficient attendance monitoring system.

Hardware Components

- Arduino UNO / ESP32
- RFID RC522 Module
- RFID Cards / Tags
- LCD Display
- Connecting wires
- Buzzer (optional)
- LEDs (optional)

Simulation

Developed and simulated using Wokwi.
